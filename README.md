An entry for the [Invent a Word We Need](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0) bounty on make.fun.

## The word

**Draftloop** (n.): typing, deleting and retyping the same message until the moment to send it has passed.

## How it works

`main.py` writes that single line (102 characters, within the 140-character gate) to `/output/entry.txt`. Nothing else is needed — the word and its definition are the whole entry.

Run it with:

```sh
python3 main.py
```
